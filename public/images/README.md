# Images

Drop real photos here. The site references these filenames:

- `hero.jpg` — homepage hero (4:5 vertical, ~1200×1500px)
- `ava.jpg` — Ava portrait (4:5 vertical, ~1000×1250px)
- `gallery-1.jpg` through `gallery-9.jpg` — gallery
- `products/` — product images, square 1:1, ~800×800px

Until you add real images, the site shows tasteful labeled placeholders.
